# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

- `run` reported a unit past its retry budget with the failure reason of the
  previous pass wrapped inside the new one, once per pass — on a real book
  three levels deep, with the actual defect buried at the end. The reason is
  now peeled to its core before it is wrapped (`llm._core_reason`).
- When unresolved files share one glossary entry no retry ever satisfied, the
  closing report says so: `⚠ the pinned 'house' = 'casa' was never met in 12
  file(s)`, with the two possible causes (a rendering wrong for that book, or
  a second sense of the term — `[exceptions]`). Until now the report's advice
  pointed only at the opposite case, an unpinned term, and the entry had to
  be found by hand. A term becomes a conflict only across two files or more:
  one file can be a genuinely hard unit (`structdiff.glossary_conflicts`).

## [1.0.1] — 2026-09-02

- The Homebrew instructions shipped with 1.0.0 named a tap that does not carry
  this formula. This repository **is** its own tap:
  `brew tap g-battaglia/ai-epub-translator https://github.com/g-battaglia/ai-epub-translator`
  then `brew install g-battaglia/ai-epub-translator/ai-epub-translator`. A PyPI
  page shows the README of the artefacts, and those are immutable — the only way
  to correct it is a release.
- The release workflow skips the upload when the version is already on PyPI, so a
  release published by hand no longer fails the run; the GitHub release and the
  formula refresh still happen.

## [1.0.0] — 2026-09-02

First public release.

- Installed globally from PyPI (`uv tool install ai-epub-translator`) or, on a
  Mac, with Homebrew: this repository is its own tap, and the formula
  (`Formula/ai-epub-translator.rb`) is generated by `tools/brew_formula.py` and
  refreshed by the release workflow once the sdist is on PyPI.

- The model translates prose units with the inline markup replaced by
  placeholders; the original tags are spliced back deterministically. Measured
  on a 77-chapter book: 98.7 % of units valid at the first attempt, 100 % after
  one retry, including four chapters the previous approach never got through.
- Every unit is cached the instant it validates: a crash or a Ctrl-C costs one
  batch.
- Deterministic checks on every file (structure, attributes, ids, page breaks,
  length, glossary), then a quality gate where the model judges each chapter,
  polishes what it flags, and blocks the EPUB if a chapter still reads wrong.
- Terminology glossary with per-context exceptions.
- Configuration in `~/.config/ai-epub-translator/config.toml`; a library of books
  with a visible `book.toml`, `glossary.toml` and finished EPUB per book and the
  machinery in `.work/`.
- `doctor`, `config init/show`, `path`, `units`, `status` with the failing
  units named.
- Agent skills (`skills/`, Agent Skills layout) for setting a book up and building its glossary.
